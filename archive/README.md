# Archive Index

`previous-bundle-v0.2/` preserves the prior delivered research package as a historical project snapshot. It is retained for traceability, not treated as an automatically verified source of truth.

When an archived claim is reused:
1. identify its exact file and prior version;
2. map it to a current `source_id` or `claim_id`;
3. re-check the underlying source and its date/version;
4. retain unresolved status if the original evidence is unavailable.

Do not silently edit the archived copy. Record corrections in the active documentation or a migration note.
