## 事件页面里公开的代码摘录如何处理

把它保存为**文章中公开的代码摘录**，保留 URL、访问日期、页面段落/行号与 SHA-256（如本地归档）。不要把它重命名为“原始内部源码”。除非取得原始 Git 对象、commit SHA、父提交和完整 diff，否则不能声称已独立验证代码的历史上下文。

## 三条核心证据链

### A. LlamaGen → T5 → 文本特征缓存 → 训练结果
需要核验模型身份、权重、tokenizer、缓存、主模型训练配置和 job ID。

### B. Goku → 公开代码/训练系统 → 多 rank 作业 → loss/checkpoint
需要核验 Goku 历史代码/配置、实际 PyTorch 文件、镜像 digest、rank 级日志和 checkpoint 元数据。论文只能用于理解系统边界，不能替代事故日志。

### C. 工件来源 → 容器/运行时身份 → 训练进程实际加载
需要把 commit、构建产物、镜像、运行时 import 路径、模型文件和 job 记录连成一条时间线。

## 因果闭合标准

`工件存在差异 → 证明被目标作业加载 → 观察到组件行为变化 → 同一作业的异常与之对齐 → 排除主要替代解释 → 可复现的修复前后差异`

缺少任何一环时，都应保留“相关但未证因果”的标记。
