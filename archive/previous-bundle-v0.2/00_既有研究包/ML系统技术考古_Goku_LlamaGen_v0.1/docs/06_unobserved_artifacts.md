## 为什么论文和公开模型还不够

论文给出模型设计和汇总指标，公开仓库给出某个 release 的代码，公开权重给出某个 checkpoint；但它们不能回答事故时具体运行了哪个 commit、哪个容器、哪个模型副本、哪份缓存、哪个 job/rank 或哪个存储权限状态。

## 优先级

1. T5 实际工件、tokenizer 与缓存的哈希；
2. LlamaGen 2024 年历史 commit；
3. Goku 事故时的源码/配置和容器身份；
4. 训练 job/rank/node 日志和 checkpoint 元数据；
5. 共享存储审计、ACL 与文件恢复记录。
