# 系统架构

```text
Researcher / CLI
       |
       v
[Request Parser] ---- validates scenario schema; no shell execution
       |
       v
[Scenario Engine] ---- consumes synthetic JSON/CSV only
       |
       +----> [Artifact Registry] ---- model IDs, hashes, provenance fields
       |
       +----> [Trace Analyzer] ------- loss / rank / status summaries
       |
       +----> [Evidence Ledger] ------ claim, source, grade, limitation
       |
       v
[Report Writer] ---- report.md + report.json + events.jsonl + manifest
```

## 逻辑平面

- **控制面**：版本/配置登记、场景输入、审批状态（在模拟中为 JSON）。
- **数据面**：合成模型登记、tokenizer 记录、文本特征缓存元数据、checkpoint 占位文件。
- **执行面**：合成 job、rank 和训练指标；不启动真实分布式训练。
- **证据面**：来源账本、SHA-256、事件序列、报告与缺口清单。
