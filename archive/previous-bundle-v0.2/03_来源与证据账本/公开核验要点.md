# 公开核验要点（访问日期：2026-10-26）

## LlamaGen

官方仓库 README 说明它包含预训练模型权重与训练/采样 PyTorch 代码，标注 `torch>=2.1.0`；README 的更新历史列出 2024-06-11 的代码/demo 发布与 2024-06-28 的文本条件模型发布。当前仓库含 `autoregressive/`、`dataset/`、`evaluations/`、`language/`、`scripts/`、`tokenizer/`、`tools/`、`utils/` 等目录。

- https://github.com/FoundationVision/LlamaGen
- https://github.com/FoundationVision/LlamaGen/blob/main/GETTING_STARTED.md
- https://github.com/FoundationVision/LlamaGen/blob/main/language/README.md
- https://arxiv.org/abs/2406.06525

## Goku

论文 arXiv 日期为 2025-02-07。当前公开仓库列出 `configs/`、`goku/`、`tools/` 等目录。论文/仓库适合作为后续公开实现研究对象，但不能替代 2024 年内部源码或训练作业材料。

- https://arxiv.org/abs/2502.04896
- https://github.com/Saiyan-World/goku
- https://saiyan-world.github.io/goku/

## PyTorch

官方版本表列出 2.2.0 于 2024-01-30 发布、2.3.0 于 2024-04-24 发布、2.4.0 于 2024-07-24 发布。该时间线是公开版本事实，不证明实际训练环境使用哪一版。

- https://github.com/pytorch/pytorch/wiki/PyTorch-Versions

## T5 配置差异

当前公开 `google/flan-t5-xl/config.json` 标注 `d_model=2048`、`d_ff=5120`、24 层、32 heads；当前公开 `google/flan-t5-xxl/config.json` 标注 `d_model=4096`、`d_ff=10240`、24 层、64 heads。这些结构字段可以辅助检查配置是否匹配，但不能替代实际权重文件哈希和历史 revision。

- https://huggingface.co/google/flan-t5-xl/blob/main/config.json
- https://huggingface.co/google/flan-t5-xxl/blob/main/config.json
