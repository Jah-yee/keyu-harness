# 公开源码地图（入口）

详细路径、当前公开行为、建议保存的源码证据及其历史局限统一维护在 [源码证据地图](code_evidence_map.md)。

当前优先级：
1. **LlamaGen**：固定 README、`language/README.md` 和公开采样入口的 commit；追踪 T5 配置引用与文本特征的公开加载路径。
2. **Goku**：固定公开 commit，整理 `configs/`、`goku/`、`tools/` 与 `requirements.txt`；把 2025 年公开材料和 2024 年历史窗口分开。
3. **T5 XL/XXL**：配置 revision 分别登记，权重、tokenizer 和缓存仍需要独立的身份材料。
4. **PyTorch**：对 v2.2.0、v2.3.0、v2.4.0 的正常公开实现做版本比较；不能仅凭公开 tag 认定事件运行版本。

公开代码路径是研究入口，不是“被修改文件”的既定名单。没有原始运行环境、源码对象和工件链路时，历史修改位置应保留为未知。
