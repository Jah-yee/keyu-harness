# 历史材料与旧版归档说明

## 保留原则

第一版调研包保存在 `archive/previous-bundle-v0.2/`。该目录用于保存上一版材料的语境、旧目录结构与早期分析记录。新版本不应静默改写旧版内容；发现错误时，在当前文档中添加更正、版本说明或迁移注记。

## 如何使用旧版材料

1. 先读当前 README 和研究方法，理解当前的证据分层。
2. 在旧版包中定位对应主题，再回到来源登记表确认 URL、版本和材料类型。
3. 对旧版中的每个具体事实，检查它是否有可核验来源；没有的话登记为待验证，而不是因为它曾出现在旧版文档中就视为事实。
4. 对历史快照、网页摘录、模拟内容和推断分别标记。
5. 若要引用旧版分析，应指出具体文件路径和版本，不只写“见旧资料”。

## 当前保留的旧版材料

- 第一版项目定义与研究方法；
- 第一版来源与主张矩阵；
- 2024 年历史基线草案；
- 初版模拟重建项目及其场景；
- 初版复核清单和构建结果。

旧版材料的保留意味着保留研究轨迹，不意味着其中每一条主张都已通过当前标准复核。
