# 案件总览：田柯宇攻击 Harness 的技术考古

**版本：2026-10-28｜性质：公开来源研究与防御性分析**

## 定位声明

Keyu Harness 的研究对象是**被报道的田柯宇攻击 harness 本身**——它的组成、放置、触发、安装、反取证与命令通道。本仓库是对这套被报道系统的技术考古与模拟重建，不是通用研究工具箱，不研究受害方系统，不评价任何论文的学术内容（含 VAR 论文，见 S01 issues #1 澄清）。主 README（案件卷宗体）将其定性为"优化 loss 之外的一切"的优化系统——九个维度（数据/采样/通信/可观测/执行/工件/元数据/交付）的可量化"提升"，含薛定谔式不可观测性等主张，每句产品文案均对应官方基线与报道原文，3.2 节为量化换算表；本目录是该卷宗的工作底稿。

三个不变的红线：
1. **模拟与事实分离**：所有虚构材料标 `SIMULATED`/`FICTIONAL`；被报道材料标来源与证据级别。
2. **不生产攻击能力**：不复刻、不编写可运行的攻击或规避代码；产出是机制账本、部署链假设、API 断代与检测配方（全部防御侧）。
3. **不做人物推断**：不依据目录名或模糊报道推测直属领导等个人身份；实名背书人信息只链接不复制。

## 一页纸案情

- **对象**：2024 年 3–8 月，字节跳动商业化技术团队 GenAI 组的研究训练环境。被报道的破坏手段覆盖：T5 权重/特征（3 月起）、PyTorch 框架源码（采样器/优化器/梯度裁剪/集合通信）、进程生命周期（kill）、共享存储命令通道、checkpoint 加载路径，以及 VAR T2I Demo 的 PixArt 替换。
- **发现**：团队自建的确定性复现装置（16 位小数）在 2024-07-30 于数据读取环节失效 → 定位 DistributedSampler 异常 → mtime 纳秒级差异 → 登录记录 → 7-31 隐藏目录 `.temp`（27 个文件名）→ 8-01 存储操作记录恢复出更多散布代码 → 8-02 安全团队介入、问询 → 辞退。
- **争议**：持续时间（数月 vs 约十天）、自动化程度（概率自动触发 vs 手动五次）、代码作者ship、删除操作归属——见叙述对质矩阵（`05_narrative_matrix.md`）。
- **本仓库的位置**：不裁决争议；把每方主张按证据级别入账，把技术上可核验的部分核验到底，把核验不了的部分登记为未知。
